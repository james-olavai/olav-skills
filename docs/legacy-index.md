# Former platform documentation archive

The [preserved legacy manual](legacy/index.md) describes the former OLAV platform. Its pages retain historical commands, versions, product terminology and capability claims for provenance. They are not instructions for the current standalone `olav-skills` package and do not establish current acceptance.

For current use, start with [installation](installation.md), the [offline example](offline-data.md) and [compatibility](reference/compatibility.md). For an existing platform consumer, read [migration](migration.md) before changing its environment or data.

The archive preserves the original public content and license/source context. It does not import the old platform runtime into Skills or add absent harness, memory, service, simulator or workflow-engine features. Retained source history and this local documentation migration do not themselves archive PyPI projects, synchronize remote repositories or switch a live site.
