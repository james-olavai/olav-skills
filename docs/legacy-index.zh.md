# 旧平台文档归档

[保留的历史手册](legacy/index.md)描述旧 OLAV 平台，页面中的历史命令、版本、产品术语和能力声明为来源记录而保留。它们不是当前独立 `olav-skills` 的操作说明，也不证明当前验收。

当前使用请从[安装](installation.md)、[离线示例](offline-data.md)及[兼容性](reference/compatibility.md)开始。已有平台消费者在改变环境或数据前，应先读[迁移](migration.md)。

归档保留原公开内容和许可/来源上下文，不会把旧 runtime 引入 Skills，也不增加宿主、记忆、服务、模拟器或工作流引擎。保留源码历史和本地文档迁移本身，不等于 PyPI 归档、远端仓库同步或现役站点切换。
