当前发行是已发布到 PyPI 的统一 **`olav-skills` 0.1.1**。发行包、Python 导入与 CLI 均独立于退役平台包。包元数据要求 Python 3.11 或更新版本。确定性脚本需要已安装依赖，portable 知识不等于 runtime。

## 数据与能力兼容

沿用 `.olav` 布局和 `OLAV_HOME` 名称，但历史库兼容须用授权副本测试。命令视图取决于输入/解析器。有界元数据 health、内置拓扑关系及厂商解析视图覆盖不同，某一项存在不能证明其它项可用。应检查 context、缺来源和 `absent_layers`。

本手册可复现流程面向原生离线 DuckDB。保留的服务端/API-client/DuckLake 消费者和私有 WebUI 集成有独立合同。包安装或本地候选通过，不验收也不切换其部署。

公开包不包含设备采集连接、模拟器、自动记忆/学习循环、通用代理宿主、调度服务或可执行工作流引擎。两个 portable 工作流明确仅为元数据，缺模拟器能力。源码引用历史缺失工具不会把它们加入产品。

## 升级验收

新 venv 安装审阅版本，执行包检查和合成示例，从该解释器重新安装技能，再验证实际宿主发现。然后用授权数据副本测试目标真实流程。自然问答保持原题，检查实际调用与最终答案，保留失败。指定脚本名的工具合同测试只证明该调用链路。

若比较模型/性能，应记录模型/provider 版本、设置、数据、prompt 版本、缓存/顺序、token/工具数及语义正确性。缺指标保留未知。上述确定性检查不能推出提速、降本或跨宿主模型质量结论。可回退升级边界见[安装](../installation.md)及[迁移](../migration.md)。
