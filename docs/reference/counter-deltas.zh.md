# 接口计数器增量

未发布的原生候选提供 `reporter compare_counters`，用于比较两次明确历史快照中的 Cisco IOS `show interfaces` 累计计数。

```bash
printf '%s\n' '{
  "snapshot_id_1": "snap_before",
  "snapshot_id_2": "snap_after",
  "device": "Edge-1",
  "interface": "GigabitEthernet0/1",
  "limit": 20
}' | olav-skills run reporter compare_counters
```

先将 `OLAV_HOME` 设为获授权的原生项目绝对路径。两个快照 ID 必填且必须不同。`device` 和 `interface` 可选，按原样精确筛选。接口名使用历史记录里的规范化写法。`limit` 可取 1 至 50，默认 20。

命令读取原生历史表 `netops.parsed_outputs`，按设备名和规范化接口名的字节匹配。结果包含使用的命令、平台、数据库 SHA-256 和所选观测的完整计数。样本按设备、接口排序。仅单边出现的接口仍计入该侧观测数，其增量和速率为 null。采集覆盖范围保持未知。

| 字段 | 观测计数 | 速率 |
| --- | --- | --- |
| `input_errors` | 输入错误数 | 错误/秒 |
| `crc` | CRC 错误数 | 错误/秒 |
| `output_errors` | 输出错误数 | 错误/秒 |
| `queue_drops` | 输入队列丢包数 | 包/秒 |
| `queue_output_drops` | 总输出丢包数 | 包/秒 |

计数类别可能重叠，逐项解读。每个样本保留两条原始读数。接受最多 38 位十进制非负整数，包括原生解析器生成的十进制字符串。缺失或无效读数返回 null。非下降的读数对可计算增量。缺乏进一步证据时，读数下降报告为 `possible_reset_or_wrap`，计数器位宽和回绕次数保持未知。

## 采集时间与重置

速率要求两条命令观测都拥有带时区的已知采集时刻，且间隔严格为正。时间证据来自历史解析行的明确命令级采集列，或身份和 SHA-256 通过核验的历史账本命令头。仅有日期、无时区时间、冲突证据、整包时间和导入时间均不足以计算速率。默认原生导入可以保留前后读数，精确命令时间可能缺失。速率未知时，仍可报告有证据支持的增量。差值方向由请求中快照的顺序确定。

精确的 IOS `show version` 观测可以确证重启。重启时间须严格落在两次接口采集之间，版本命令采集时间须等于或晚于重启时间。核验过的历史原文中，若匹配接口段的明确清零时点或受支持的 `HH:MM:SS` 整段时间范围严格落在两次采集之间，可确证一次清零。确证中断时返回证据，增量和速率均为 null。比较依据已记录的设备和接口身份，未记录的重置、回绕和硬件更换仍有可能。

该命令适用于 64 位 Linux 原生数据库，以只读方式读取经核验的私有副本，执行限时 10 秒，并固定数据、内存和响应预算。完整观测计数独立于样本条数。范围超出处理预算或身份存在歧义时，命令返回错误，计数为 null。
