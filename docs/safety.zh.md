# 权限、写入与证据边界

请根据任务为进程配置文件系统、环境和执行权限。标准技能正文及安装器元数据分别是指令和归属记录，不构成操作系统隔离或逐用户授权系统。

## 识别写操作

| 操作 | 预期影响 |
| --- | --- |
| `version`、`list`、`doctor` | 检查包与运行环境 |
| `install`、标准 `export`、portable 导出 | 向指定目标写入技能或知识文件 |
| `validate_bundle` | 读取规范包并校验完整性，不导入数据库 |
| `survey_bundle` | 可能解压或归一化输入，生成新的准备目录 |
| `ingest_snapshot` | 写入分析库、派生状态与导入报告 |
| 有界 SQL 读取 | 只读 SQL；可选 `export_bounded` 会写预览 CSV |
| `draw_topology` | 读取限定范围关系并写图表 |
| `finish_learn`、`save_recipe`、`rebuild_views` | 保存解析器/recipe 或重建数据库派生视图 |

本表描述预期路径，并不在所有 Python 代码外建立沙箱。可信脚本拥有进程本身的权限。宿主应限制可挂载数据与输出根，避免把凭据传入子进程，实验使用授权副本。导入 Python 前先设置 `OLAV_HOME`；也要明确工作目录，因为部分相对产物路径按 CWD 解析。

## SQL 是有界读取入口

模型生成查询时优先使用 `analyzer execute_sql`，不要自行打开管理连接。SELECT/WITH 通过只读连接执行，行数、单元格、响应字节与时间均有限制；SQL 外部文件/网络访问会被拒绝。修改语句返回 `requires_approval`，不会执行；这个状态不提供审批接口，也不会在聊天回复后自动执行。CLI 不提供通用 SQL 管理能力。

仅选择所需字段，值使用绑定 `params`，分页保持稳定排序。不要倾倒完整原始配置。`export_bounded=true` 在适用的截断结果路径中仅导出返回的有界预览，不保证全量导出。

## 审阅输入与输出中的敏感信息

离线采集可能包含凭据、地址及客户信息，应使用授权传输和存储，分享前审阅脱敏效果。manifest 哈希证明字节一致性，不证明发送者身份、内容安全或采集授权。声明 `pre_scrubbed` 也不能证明没有秘密。解析器候选属于需审阅的代码/数据，样本通过不能证明普遍正确。

报告与图表继承来源的敏感性，发布前检查内容与目标访问权限。Portable 导出传递包知识，不授予数据库或宿主工具访问权。

## 让结论保持在证据范围内

写明所选快照、采集时间来源、来源视图及限制。角色/时间未知不等于零；拓扑覆盖缺失不等于没有协议；基于图的影响计算不等于数据包可达性模拟。变更草案在应用前需要工程审阅与当前状态核对，本包不会下发设备配置。

模型指令不能替代文件系统控制和宿主授权。宿主审批、多用户身份、租户隔离及服务操作属于独立集成责任。另见[数据语义](data-model.md)、[portable 边界](portable.md)与[兼容性](reference/compatibility.md)。
